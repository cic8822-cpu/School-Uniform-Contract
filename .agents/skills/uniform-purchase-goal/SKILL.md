# 교복구매 길라잡이 /goal 운영

이 스킬은 Codex의 내장 `/goal`을 프로젝트 작업 단위에 안전하게 적용하는 운영 규칙임. `/goal`은 별도 구현 기능이 아니라 Codex의 세션 범위 기능이며, 현재 버전이 이를 지원하고 워크스페이스가 신뢰되며 hooks가 비활성화되어 있지 않아야 함.

## 사용 전 점검

1. `Codex --version`으로 Codex가 목표 기능을 지원하는 버전인지 확인함.
2. 작업 범위를 한 번에 하나의 검증 가능한 완료 조건으로 제한함.
3. [계획.md](../../../계획.md)의 선행 항목과 완료조건을 읽음.
4. 원본 파일 보호, 개인정보 비노출, 배포·외부 전송 전 사용자 확인 원칙을 조건에 포함함.

## 목표 작성 규칙

- 완료 조건, 확인 방법, 변경 금지 범위를 한 문장에 명시함.
- 평가자는 대화에 표시된 결과만 판단하므로 검사 명령·검증 결과·생성 파일 경로를 작업 중 응답에 남김.
- 세션당 활성 목표는 하나임. 새 목표는 기존 목표를 대체함.
- `/clear`은 활성 목표도 지우므로, 맥락을 정리하기 전에 `/goal` 상태를 확인하고 필요한 경우 목표를 다시 설정함.

## 프로젝트 목표 템플릿

### P0~P1 분석·인벤토리

`/goal 계획.md의 P0-02·P0-03·P1-01~P1-03 산출물이 생성되고, HWPX 서식·이미지·참고자료의 수치가 구분되어 기록되며, XLSM 외부 링크·연결·VBA 의존성이 분류되고, 모든 생성 문서의 오류 검사와 git diff --check가 통과하며 원본 HWPX·XLSM은 변경되지 않음.`

### P2 HWPX POC

`/goal 대표 HWPX 3종의 사본 템플릿화·값 치환·저장·재열기·kordoc validate·PDF 비교 결과가 kordoc_기술검증.md에 기록되고, 한컴 열기와 행정실 직원의 수동 확인 항목이 명시되며, 원본 파일은 변경되지 않음.`

### P3 Excel MVP

`/goal 확정된 교복구매 서식이 XLSM에 구현되고, 공통 기초자료가 각 서식에 반영되며, 외부 링크·외부 연결·#REF! 이름 정의가 0건이고, 골든 데이터의 정상·누락·최대길이·복수행 테스트와 PDF 출력 검증이 통과하며 계획.md·test.md·체크리스트.md·로그.md가 갱신됨.`

## 상태·재개·해제

- `/goal`: 현재 조건, 경과시간, 평가 턴 수, 최근 평가 사유 확인.
- `/goal clear`: 목표를 취소. `stop`, `off`, `reset`, `none`, `cancel`도 동일함.
- 세션을 재개하면 활성 목표의 조건은 복원될 수 있으나 턴 수·시간·토큰 기준선은 초기화됨.
- 목표가 복구 불가능 오류로 해제되면 원인을 수정한 뒤 같은 조건 또는 축소한 조건으로 `/goal`을 다시 설정함.

## 운영 제약

- `/goal`은 도구 권한을 자동 변경하지 않음. 무인 실행에는 별도 자동 모드가 필요함.
- 배포, 외부 API 발송, `git push --force`, 대량 삭제, 시크릿 파일 수정은 `/goal` 중에도 사용자 확인이 필요함.
- 장시간 백그라운드 작업이 있으면 목표 평가는 작업 완료 뒤로 연기될 수 있음.
- 평가자가 자체적으로 파일을 읽거나 명령을 실행하지 않으므로, 수행한 검증의 결과를 숨기지 않음.
