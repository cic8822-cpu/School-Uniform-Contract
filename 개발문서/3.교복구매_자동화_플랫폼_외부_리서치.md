## 3. 부산광역시교육청 — 원클릭생활교육

### 3-1. 서비스 개요
- **URL**: https://home.pen.go.kr/oneclick/cm/cntnts/cntntsView.do?cntntsId=1766&mi=12204
- **출처**: https://www.pen.go.kr (부산교육청)
- **형태**: 원클릭생활교육 웹사이트 하위 정보 페이지

### 3-2. 교복구매 콘텐츠
- **절차 안내**: 8단계로 구체적 절차 설명
  1. 교복디자인 선정·공개 + 학교구성원 의견수렴
  2. 교복 구매 계획 수립 (상한가격 반영)
  3. 학교운영위원회 심의
  4. 입찰공고 (관련 법련 준수)
  5. 교복 납품 사업자 선정 (2단계 절차: 품질 → 가격)
  6. 수납 및 학교회계 처리
  7. 검수 및 평가환류
  8. 대금 지급 및 사후 평가

### 3-3. 서식 자동화
- **결과**: ❌ 서식 다운로드/자동 생성 기능 없음
- **제공 방식**: 텍스트로 절차만 설명, PDF 매뉴얼 참조

### 3-4. 차별화 포인트
- **향후 교복 정책 방향** (참고용):
  - 교복간소화 또는 생활복 권장
  - 부산광역시교육청 표준디자인 활용
  - 학생 개성발현권, 자기결정권 보장
  - 하의를 면바지로 대체, 체육복 형태 교복 대체
  - 금색단추, 파이핑 배제, 주머니 최소화
  - 교복 원단 체크무늬 배제

## 5. S2B(학교장터) — 전국 교육기관 전자조달 시스템

### 5-1. 서비스 개요
- **URL**: https://www.s2b.kr
- **운영**: 한국교직원공제회
- **대상**: 전국 21,000여 개 교육기관
- **거래 규모**: 2022년 기준 91만건, 1조1855억 원

### 5-2. 주요 기능
| 기능 | 설명 |
|---|---|
| 견적정보 | 다수 공급업체의 사전 등록 견적서 확인 |
| 수의계약 | 1인/2인 수의계약 (단일/공개 견적) |
| 입찰 | 일반경쟁입찰/제한경쟁입찰/지명경쟁입찰 |

### 5-3. 계약 서식 자동화
- **서식 자동 생성**: ✅ "계약법령에 부합된 시스템... 각종 계약서식이 자동으로 제공"
- **에듀파인 연계**: 계약서작성, 원인행위서 작성 등 자동 적용
- **S2B vs G2B(나라장터)**: 
  - S2B: 교육기관 전용, 2,000만원 이하 소액 조달 특화
  - G2B: 모든 공공기관, 대형 건축/공사 중심

### 5-4. 우리 프로젝트 연관성
- **참고점**: 계약서식 자동 생성 기능 (한국교직원공제회 운영)
- **차별점**: S2B는 입찰/계약 중심, 우리는 교복구매 전 과정(예산편성~사후평가) 가이드

## 10. 우리 프로젝트에 적용할 수 있는 참고 사항

### 10-1. 서식 구조 참고
- **서울교육청**: "입력 → 다운로드 → 출력 → 전체출력" 일원화 구조
- **전북교육청**: 교복선정위원회 위원 명단, 교복 디자인·규격서, 사양서, 계약 특수조건 등의 서식 구조
- **경기도교육청**: 품질심사 체크리스트, 검수 확인서, A/S 계획서 등의 상세 구조

### 10-2. Excel 자동화 패턴 참고
- **입력 시트 1개 → 서식 자동 반영**: 용역계약갈라작이 xlsm의 패턴을 그대로 복제
- **체크박스 선택 → 인쇄 범위 자동 조합**: `=IF(체크박스=1,"A1:BD33,","")` 수식 패턴
- **학교정보 검색 팝업**: UserForm 기반 학교명 자동 완성

### 10-3. kordoc 기술 검증 결과 (2026.09.15 실시간 테스트)
| 항목 | 결과 |
|---|---|
| HWPX 열기/구조 분석 | ✅ 성공 (710 blocks, 64 tables) |
| 텍스트 추출 | ✅ 성공 (Markdown + JSON) |
| 표 구조 접근 | ✅ 성공 (row/col/cell 구조 파악) |
| 필드 자동 감지 (fill --dry-run) | ✅ 성공 (60+ 필드 자동 인식) |
| 텍스트 치환 (fill) | ✅ 성공 (25개 필드 치환 완료) |
| 스타일 보존 | ✅ hwpx-preserve 모드로 검증 |

**검증 명세**: `npx -y kordoc@^4 fill --dry-run sample.hwpx` → 60개 필드 자동 인식 → `npx -y kordoc@^4 fill sample.hwpx -f '교감=김민교...'` → 25개 필드 치환 → `npx -y kordoc@^4 validate` → 구조 검증 통과

### 10-4. 웹앱 기술 스택 제안
| 옵션 | 장점 | 단점 | 추천 여부 |
