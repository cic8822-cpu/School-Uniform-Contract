## 4. P2 인계 조건

1. 대표 3종을 선정한 뒤 각 Form ID의 필드 ID를 사본 HWPX 템플릿의 실제 토큰·셀과 대조함.
2. 반복행은 최대 행 수와 빈 행 제거·페이지 분할 결과를 HWPX·PDF로 검증함.
3. 계약 문구, 법령, 금액기준은 자동 판단·임의 변경하지 않으며 행정실 담당자가 결과를 최종 확인함.
4. 보호 필드는 HWPX 치환 JSON, 테스트 로그, Git, 웹 전송에서 제외하고 마스킹 시험값만 사용함.
