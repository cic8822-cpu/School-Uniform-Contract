## 2. 제외 및 보류 범위

- 52개 원본 서식의 Excel 조판·개별 PDF 출력은 P3-02에서 구현·검증함.
- 실제 문서 데이터, 학생·학부모 개인정보, 서명·직인은 입력하지 않음.
- HWPX 출력은 P2-01의 독립 템플릿 확보 전까지 제공하지 않음.
- 입력값 초기화 매크로와 선택 인쇄 기능은 P3-02에서 새 VBA 범위로 설계·검증하며, 기존 XLSM VBA는 이식하지 않음.

## 4. 기준 수준 구현을 위한 재작업 조건

1. 기준 XLSM의 실제 입력 흐름, 서식 구성, 선택·출력 제어, 인쇄영역 및 사용자 조작을 화면·기능 단위로 분석함.
2. 분석 결과를 기준으로 `02_기초자료_입력`을 단순 목록이 아닌 실무 입력 화면으로 재구성하고, 공통값 자동 반영과 필수값 오류 표시를 구현함.
3. 최소 대표 서식부터 원본 수준의 표·병합·인쇄 조판과 선택 출력 기능을 구현하고 Excel/PDF를 직접 비교함.
4. 대표 서식 검증 뒤 52개 Form ID로 확장하며, 골든 테스트와 행정실 확인을 모두 통과해야 완료 처리함.

P2-01은 별도 독립 HWPX 사본·안전한 분리 방법·고유 토큰이 확보될 때까지 `BLOCKED`로 유지함.
