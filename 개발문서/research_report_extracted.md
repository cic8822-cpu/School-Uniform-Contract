\*\*교복구매 자동화 플랫폼 - 외부 리서치 보고서\*\*

\*\*목적\*\*: 타 교육청·지자체·사업체 SaaS의 교복구매 계약 서식 자동화 사례 조사

\*\*조사일\*\*: 2026. 09. 15.

\*\*조사 방법\*\*: Web search + Web extraction + kordoc 기술 검증

## 1. 서론

\*\*배경\*\*: 학교 교사·행정실 직원들이 교복구매 공문·계약서·적격심사평가표 등을 작성하기 어려워 자동화 플랫폼이 필요함

\*\*목표\*\*: 타 교육청/지자체/민간 사례를 분석하여 우리 프로젝트의 참고 자료 마련

## 2. 주요 조사 결과

### 2-1. 서울특별시교육청

\*\*URL\*\*: https://contract.sen.go.kr
\*\*서비스명\*\*: 서울교육청 계약길잡이
\*\*교복구매\*\*: 별도 메뉴 존재 (gb=A1, gy=B02)
\*\*서식 원클릭\*\*: Excel.xlsm (VBA 매크로) 기반
\*\*장점\*\*: 공개 접근, 입력 → 다운로드 → 출력 일원화
\*\*단점\*\*: HWPX 출력 ❌, 웹 배포 어려움

### 2-2. 전북특별자치도교육청

\*\*서비스명\*\*: 서.비서 (AI 챗봇)
\*\*기능\*\*: 자연어 → 매뉴얼 검색 + 서식 자동 생성
\*\*운영 시작\*\*: 2026. 9월 (개발 완료: 2026. 4월)
\*\*대상\*\*: 초·중등 현장 교사
\*\*차별점\*\*: AI 기반 챗봇 인터페이스

### 2-3. 부산광역시교육청

\*\*URL\*\*: https://home.pen.go.kr/oneclick
\*\*서비스명\*\*: 원클릭생활교육
\*\*교복구매\*\*: 8단계 워크플로 텍스트 안내
\*\*서식 자동화\*\*: ❌ (텍스트 안내 수준)

### 2-4. 경상남도교육청

\*\*사례\*\*: 10종 계약 서류 → 1종 통합서약서로 간소화
\*\*성과\*\*: 사업자 업무 88.7% 감소, 공무원 90.7% 만족

### 2-5. S2B(학교장터)

\*\*URL\*\*: https://www.s2b.kr
\*\*운영\*\*: 한국교직원공제회
\*\*대상\*\*: 전국 21,000개 교육기관
\*\*거래 규모\*\*: 2022년 91만건, 1조1855억 원
\*\*서식 자동화\*\*: 계약서식 자동 생성 (일부 제공)

## 3. 기술 검증 (kordoc)

| 항목 | 결과 |
|---|---|
| HWPX 구조 분석 | ✅ 성공 (710 blocks, 64 tables) |
| 필드 자동 감지 (fill --dry-run) | ✅ 60+ 필드 인식 |
| 텍스트 치환 (fill) | ✅ 25개 필드 치환 |
| 구조 검증 (validate) | ✅ 통과 |
| HWPX 생성 (generate) | ✅ Round-trip 성공 |

## 4. 기존 Excel 템플릿 분석

\*\*시트 수\*\*: 64개 (기초자료\_입력 + 별표1\~25 + 붙임1\~15)
\*\*입력 방식\*\*: B열 노란 셀 입력 후 VBA 버튼으로 출력
\*\*출력 방식\*\*: PDF / Excel (HWPX ❌)
\*\*한계점\*\*: HWPX 출력 불가, 웹 배포 불가, 팝업 입력 UI 없음

## 5. 결론 및 제안

### 5-1. 우리 프로젝트의 차별점

\*\*HWPX/PDF 이중 출력\*\*: kordoc 기술 검증 완료
