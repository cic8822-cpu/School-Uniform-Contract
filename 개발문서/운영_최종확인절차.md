# 교복구매 길라잡이 운영·최종 확인 절차

## 사용 전

1. `기초자료입력`에서 학교명, 학년도, 구매명, 제목, 계약방식, 기초금액, 납품기한을 확인한다.
2. 업체·위원·품목 반복행은 실제 업무자료와 대조한다. 학생·학부모 개인정보, 서명, 설문 원자료는 입력하지 않는다.
3. F-016 정성평가는 재질·완성도·A/S·하자보상에 `탁월·우수·보통·미흡·불량`만 선택한다. 가감점은 근거자료를 확인한 뒤 입력한다.
4. 계약방법은 금액으로 자동 판정하지 않는다. `계약방법안내`의 유형을 선택한 뒤 적용 법령과 학교 계약 기준을 행정실이 확인한다.

## 저장과 출력 전

1. `[저장하기]` 또는 `[수정하기]` 뒤 파일이 실제 저장되었는지 확인한다.
2. `서식선택_출력`에서 필요한 Form ID와 구현상태를 확인한다. F-013은 HWPX 경로로 처리한다.
3. 미리보기에서 학교명·학년도·날짜·계약방식·업체 선택값·점수·합계를 원자료와 대조한다.
4. 개인정보 가능 문서 F-029, F-047, F-050은 빈 양식만 출력한다.

## 행정실 최종 확인

- 계약방법, 공고·제안·계약 조건, 금액, 일정, 품목별 단가와 수량은 담당자가 최종 확정한다.
- 결재란의 담당자·교장 이름은 표기만 자동화하며 서명·직인은 수기 절차를 따른다.
- PDF에서 표가 가로로 분리되지 않았는지, 긴 제목·안내문·전화번호·결재란이 잘리지 않았는지 확인한다.
- 출력본은 결재·공고·계약에 사용하기 전에 학교의 최신 지침과 원본 서식을 대조한다.

## 기록

확인 중 발견한 오류, 원본과의 차이, 보류 사유는 `로그.md`에 사실대로 기록하고 수정 후 다시 미리보기와 PDF를 확인한다.
