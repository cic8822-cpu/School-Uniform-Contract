# ADR-001 — HWPX 출력 아키텍처 결정

- **상태**: DONE(확정)
- **결정일**: 2026-09-25
- **관련 Phase**: P2-03(계획.md), P4-01(현장 검증)
- **결정자**: 프로젝트 소유자(사용자) 명시 지시

## 1. 배경

`계획.md` D3(2026-09-15, CONFIRMED)는 "HWPX 출력은 대표 3종 POC 후 학교 PC의 로컬 보조도구를 우선 적용"으로 이미 방향을 정했다. P2-03은 이 방향이 실제로 동작하는지, 그리고 Excel과의 연계가 기술·운영상 곤란하지는 않은지 최종 판정하는 게이트였다.

## 2. 검토한 대안

| 대안 | 내용 | 채택 여부 |
|---|---|---|
| A. Excel VBA + 로컬 PowerShell 보조도구 | Excel 버튼 클릭 → VBA가 `Shell()`로 PowerShell 스크립트 호출 → 원본 HWPX 사본의 `hp:t` 텍스트 노드만 직접 치환(재직렬화 없음) | **채택** |
| B. Excel VBA 네이티브 HWPX 생성 | VBA만으로 ZIP·XML 구조를 직접 조작 | 미검토(과도한 재구현 비용, POC 범위 밖) |
| C. 웹앱에서 HWPX 생성 | 브라우저/서버에서 HWPX 생성 후 다운로드 | 기각(D3 단계에서 이미 로컬 우선으로 결정, 검증되지 않은 채로 "웹 브라우저 내 HWPX 생성 약속"은 계획.md 1.3절 MVP 제외 항목) |

## 3. 결정

**대안 A(Excel VBA + 로컬 PowerShell 보조도구)를 채택한다.** 이미 구현·검증된 경로(`scripts/export_hwpx_p204_from_excel.ps1`, `scripts/hwpx_school_footer_fill.ps1`)를 그대로 운영 방식으로 확정한다.

### 3.1 기술 검증 근거

- P2-04(2026-09-23~24)에서 47개+ Form ID 전체를 원본 보존형 템플릿으로 분리하고, Excel "HWPX 작성" 버튼 → PowerShell 스크립트 호출 경로로 48/48 성공 생성을 확인함.
- 2026-09-24 HWPX 작성 버튼의 종료 코드 1 오류(열려 있는 xlsm에 `Get-FileHash`가 `FileShare.Read`로 접근해 충돌)를 근본 수정하고, 실제로 xlsm을 열어둔 상태에서 재현·재검증함(`로그.md` 2026-09-24).
- 2026-09-24 사용자가 한컴에서 직접 열어 결재란·병합표·레이아웃을 육안 확인하고 통과로 확정함(P2-02, `test.md` H-05).

### 3.2 현장 검증(P4) 갈음 근거 — **사용자 결정, 제한사항 명시**

사용자가 2026-09-25 다음과 같이 명시적으로 지시함(원문 요지): "내 로컬에서 되는 게 학교 PC에서도 된다. 사무실과 집을 계속 왔다갔다 하며 작업하면서 확인한 것이므로 검증 완료로 하고 통과."

이에 따라 `계획.md` P4-01(현장 검증)의 원래 완료조건("신규 담당자도 5개 대표서식 생성 완료", "관찰기반 사용성 테스트")을 다음으로 대체하고 완료 처리한다:

> 사용자 본인이 서로 다른 물리적 PC 2대(사무실·자택)를 오가며 반복적으로 Excel MVP·HWPX 생성 기능을 사용·확인한 이력을 현장 검증으로 인정한다.

**이 결정이 검증하지 못한 것(정직성 기록)**:
- 실제 학교 행정실의 신규 담당자가 사전 설명 없이 처음 사용했을 때의 사용성·오류 발생 여부
- 학교 행정실 PC의 실제 보안 정책(PowerShell 실행 정책 제한, 매크로 차단 정책, 한컴오피스 버전 차이 등)에서의 동작 여부
- 사용자 본인 PC 2대는 모두 동일인이 설정·관리하는 환경이라, 제3자 환경에서 발생할 수 있는 설정 차이(예: PowerShell 실행 정책이 `Restricted`로 잠긴 학교 PC)를 배제하지 못함

위 잔여 리스크는 실사용 중 문제가 보고되면 `로그.md`에 즉시 기록하고 대응한다.

## 4. 한계 및 후속 조치

- 실제 학교 행정실 PC에서 문제가 발생하면(특히 PowerShell 실행 정책 관련 오류), 대안 C(웹앱 HWPX 생성)로 전환할 수 있도록 웹앱 설계(P5) 시 HWPX 생성 로직을 Excel/로컬 스크립트에 종속시키지 않고 별도 모듈로 분리해 두는 것을 권장함.
- F-013(표·이미지 복합조판)은 계속 HWPX 경로로만 제공하며, 학교별 디자인 이미지 교체는 담당자 수동 처리로 유지함(변경 없음).
