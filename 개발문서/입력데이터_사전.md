# 입력 데이터 사전 — P1-03

- **상태**: `VERIFIED — P1-03`
- **적용 범위**: `F-001`~`F-052` 출력 서식. `F-053`~`F-057`은 읽기 전용 참고자료임.
- **근거**: `서식_인벤토리.md`, `_workspace/01_analysis/HWPX_원시구조_목록.md`
- **제약**: 원본 HWPX에 확정 변수 표식이 확인되지 않았으므로, 아래 모델은 Excel 입력과 HWPX 템플릿화의 공통 계약임. 실제 HWPX 치환 위치·반복 표 구조는 P2 사본 POC에서만 확정함.

## 4. 검증 순서

1. 출력 선택 전 대상 Form ID의 필수 공통값·문서별 값을 검사함.
2. 날짜는 시작일·종료일·제출기한의 선후 관계를 확인함.
3. 반복행은 빈 행을 제외하고 업체명·위원 역할·품목명의 중복을 경고함.
4. 계산값은 수량·단가·점수의 유효성 검사를 통과한 뒤 재계산함.
5. 보호 필드가 입력 범위·치환 JSON·로그·Git·웹 전송에 포함되면 출력을 차단함.
