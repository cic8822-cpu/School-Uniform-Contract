# 결정사항 — P1-04 범위 및 대표 HWPX POC

- **상태**: `APPROVED — P1-04`
- **결정 대상**: Excel MVP 출력 서식 범위, HWPX POC 대표 3종, 문서별 업무 검토 책임
- **근거**: `서식_인벤토리.md`, `입력데이터_사전.md`, `서식_매핑표.md`
- **제약**: 원본 HWPX·XLSM은 변경하지 않음. POC는 사본과 마스킹된 시험값으로만 수행하며, 실제 HWPX 치환 토큰·셀·반복 표 위치는 P2에서 확인함.

## 3. 공통 POC 시험 조건

1. 모든 시험값은 가상 학교명·마스킹된 역할표시·가상 품목만 사용함.
2. 개인정보 가능 문서 F-029, F-047, F-050은 대표 POC에서 제외하고, 이후에도 허용 필드 외 값은 입력·저장·치환·로그·Git·웹 전송하지 않음.
3. 계약 문구·법령·금액기준은 자동 판단 또는 임의 변경하지 않으며, 결과물은 계약 담당자가 사실관계·조건을 수동 확인함.
4. P2 완료 판단에는 Kordoc `validate`, 생성본 재열기, 한컴 수동 열기, PDF 비교, 담당자 확인 기록을 모두 포함함.
