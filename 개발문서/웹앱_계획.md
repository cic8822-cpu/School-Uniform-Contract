## 3. WP-02 세부 계획

1. **계약방법 Master**: `0-2.md` §4 표(4종·적용조건·단계수·공통/전용 서식)를 정적 JSON화. 이미 Excel `frmContractGuide`에 구현된 단계별 Form ID 배열(2026-09-25 Explore 조사로 전수 추출됨)을 소스로 사용 — 새로 설계하지 않고 이식.
2. **Workflow Master**: 계약방법별 Step 배열(1인견적 4/2인견적 5/2단계·일반입찰 11)과 단계명·업무설명·관련서식·주의사항·근거상태를 관리. Excel `frmContractGuide.초기화` 프로시저의 `stepNames`/`stepDescriptions`/`stepFormIDs` 배열을 그대로 포팅하고, 매뉴얼 근거가 없는 수의계약 단계는 “매뉴얼 확인 필요”로 구분함.
3. **Form Master**: 기존 `서식_매핑표.md`·`서식_인벤토리.md`(F-001~F-052)를 System ID/매뉴얼번호/서식명/업무단계/작성주체/사용계약방법/필요Field/출력방식 스키마로 변환.
4. **Field Master**: `입력데이터_사전.md`의 C/B/D/R/K 필드 정의를 Field ID/한글명/Type/Required/사용서식/Source 스키마로 변환.
5. **Template Mapping**: 원본 HWPX의 `{{학교명}}` 등 이미 확정된 토큰(`scripts/hwpx_token_fill.ps1`의 `$AllowedTokens`)과 Field ID를 매핑.

## 4. WP-03 세부 계획

1. 프로젝트 스캐폴딩(`웹앱_trd.md`의 기술스택 결정에 따름), `/data`·`/templates`·`/assets`·`/js` 구조(`0-1.txt` §21).
2. 홈·계약방법안내·계약절차·기초자료·서식함·내보내기·사용안내 7개 화면 구현(디자인 PDF 6종을 그대로 구현, 새로 디자인하지 않음). 화면설계 보강이 필요하면 `web-ux-designer`가 `frontend-design` 스킬을 호출하고 `ui-ux-pro-max-skill`(hermess 저장소, 설치된 스킬 아님 — 참고용 방법론) 원칙을 반영함.
3. 문서 미리보기 모달(A4) + 기초자료 자동반영 + 누락값 안내.
4. Excel Import/Export(업무자료.xlsx) 클라이언트 파싱/생성.
5. PDF 클라이언트 생성(page-break/margin/표/폰트 제어).
6. HWPX 클라이언트 생성(`lib/hwpx/tokenFill.ts` — `hwpx_token_fill.ps1` 포팅, `lib/hwpx/footerFill.ts` — `hwpx_school_footer_fill.ps1` 포팅).
7. 접근성(WCAG 2.1 AA)·반응형·오프라인 동작 QA.
8. 배포(학교 PC 로컬 설치 패키지로만 제공). 인터넷 연결 없이 실행·입력·출력·백업이 모두 가능해야 함.

## 5. 확정된 것 (변경 시 이 문서·`ADR-002` 동시 갱신)

- 서버·DB 없음, **학교 PC 로컬 설치형 Static-first 배포**(GitHub Pages·Vercel 등 외부 호스팅 제외)
- **HWPX는 웹 클라이언트에서 직접 생성함**(원본 템플릿 Field 치환 방식, 서버 미경유) — 2026-09-25 `ADR-002` 개정으로 확정
- 첫 화면은 계약방법 4종 카드 선택(9단계 허브 폐기, Excel과 동일하게 전환)
- 계약방법은 시스템이 자동판정하지 않고 사용자가 직접 선택
- 기초자료는 직접 입력 또는 Excel 업로드(둘 다 로컬 클라이언트 처리), Single Source of Truth로 전체 서식에 자동 반영
- 매뉴얼 원본 번호(`[9-7]` 등)는 Form ID와 항상 병기, 삭제·변경 금지

## 6. 확정된 운영 경계

- 웹앱과 업무자료는 학교 PC 안에서만 처리하며, 외부 서버·DB·분석 도구·외부 호스팅으로 전송하지 않음.
- 기초자료는 웹앱의 일반 서식 자동작성에 사용하고, 명시적 백업은 학교 담당자가 `업무자료.xlsx`로 내려받아 해당 학교 PC에 보관함.
- F-029·F-047·F-050은 기존 원본 보호 정책에 따라 공통 업무값만 자동 반영하고 개인식별·연락처·서명·설문 원자료는 입력·저장·자동 반영하지 않음.
