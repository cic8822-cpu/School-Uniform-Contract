- **상태**: `Excel MVP(P0~P3) 완료 · 웹앱(P5) 착수 — 2026-09-25 갱신`
- **작성일**: 2026-09-15
- **근거**: [계획.md](계획.md), [ADR-001-HWPX출력방식.md](ADR-001-HWPX출력방식.md), [ADR-002-웹앱아키텍처.md](ADR-002-웹앱아키텍처.md)

## 1. 문제와 목표

학교 담당자가 교복 학교주관구매 절차별 서식을 찾고 반복 입력하는 부담을 줄이기 위해, 공통 기초자료를 한 번 입력한 뒤 필요한 서식을 선택하여 Excel 및 PDF로 출력하는 Windows용 XLSM MVP를 구축함(완료).

이어서 같은 절차·서식 정보를 웹에서도 탐색·작성할 수 있는 정적 웹앱을 구축함. **HWPX 자동 생성은 `ADR-001`로 로컬 Excel 경로(PowerShell 보조도구)로 확정됐으며, 웹앱은 HWPX를 생성하지 않음.** 웹앱은 서버·DB 없이 절차 안내, 기초자료 입력(팝업/엑셀 업로드), 검증, 클라이언트 사이드 PDF 출력을 제공함(`ADR-002` 참고).

## 2. 사용자와 역할

| 역할 | 주요 업무 | MVP 권한 |
|---|---|---|
| 교사 | 절차 확인, 기초자료 입력, 서식 선택 | 입력·미리보기 |
| 행정실 직원 | 계약·금액·발행 문서 확인 | 최종 확인·출력 |
| 관리자 | 기준자료·서식 버전 관리 | 별도 승인 후 관리 |

## 4. 비기능 요구사항

- 새 XLSM은 외부 링크·외부 연결·`#REF!` 이름 정의가 각각 0건이어야 함.
- 원본 HWPX·XLSM은 읽기 전용이며 생성본은 `artifacts/`에만 저장함.
- 학생·학부모 정보 및 직인 자동처리는 MVP에서 제외함.
- 계약·연락처 정보는 중앙 저장·Git·로그·대화에 기록하지 않음.
- 지원 환경은 Windows, Microsoft 365, 한컴오피스임.
- 웹앱은 서버·DB를 운영하지 않으며, 기초자료 입력값(팝업 입력·엑셀 업로드 파싱 포함)을 서버로 전송하거나 저장하지 않음. 학교정보 목록만 빌드 시점 정적 데이터로 제공함(`ADR-002`).
- 웹앱의 PDF 출력은 브라우저 클라이언트 사이드에서 생성함(서버 미경유). HWPX 출력은 이번 MVP 범위에서 제공하지 않으며 Excel 로컬 경로로 안내함(`ADR-001`, `ADR-002`).
- 웹앱은 빠른 탐색·작성 보조 도구이며, 최신 공식 매뉴얼·FAQ·서식의 확인과 자동 생성 결과의 최종 검토를 대체하지 않음.

## 5. 수용 기준

1. 확정 인벤토리의 Form ID별 Excel 서식이 선택·출력됨.
2. 정상·필수값 누락·최대길이/특수문자·복수 반복행 골든 테스트를 통과함.
3. PDF와 HWPX는 별도의 기준본으로 비교하며, 웹앱 HWPX 출력 전환 시에도 동일한 HWPX 검증 기준을 적용함.
4. 행정실 직원이 생성물의 사실관계·계약조건·서식 상태를 최종 확인함.
5. `test.md`의 자동 검사와 `체크리스트.md`의 해당 Phase 게이트가 통과해야 완료로 표시함.
6. 웹앱은 단계→관련 Form ID→입력·누락 검사→미리보기·다운로드 흐름과 접근성 수용 기준을 통과함.

## 6. 범위 제외

학생별 주문·치수·설문 데이터의 수집·저장, 직인·서명 자동 처리, 법령·계약 문구의 자동 판정, 검증 전 HWPX 생성 기능, 중앙 서버/출력이력 저장은 제공하지 않음. **웹앱에서의 HWPX 직접 생성**도 `ADR-001`·`ADR-002` 결정에 따라 이번 범위에서 제외함(로컬 Excel 경로로 대체).
