## 1. 프로젝트 목표 (원본 §1 유지)

학교 교사·행정실 직원이 교복 학교주관구매 절차를 쉽게 이해하고, 필요한 공문·계약서·평가표·가정통신문·설문지·검수서식 등을 최소한의 기초정보 입력만으로 자동 작성·출력할 수 있는 「교복구매 길라잡이」 플랫폼 구축.

개발 순서(원본 유지): ① Excel MVP → ② HWPX 자동작성 검증 → ③ 실사용 검증·개선 → ④ 동일 데이터 모델 기반 웹앱 → ⑤ UX/UI 전문 검토 → ⑥ 배포 가능한 운영 형태 완성. Excel/HWPX 구조가 검증되기 전에는 웹앱으로 넘어가지 않는다.

## 4. 가정/결정사항 (질문 대상 아닌 것, 합리적 가정 후 진행)

- [결정] kordoc 1순위 유지(원본 §11). ZIP/XML 직접 조작은 kordoc이 지원하지 않는 기능에 한해 대안 순서대로 적용. `{{VARIABLE}}` 치환 전략은 원본 §10 그대로 유지.
- [결정] ui-ux-pro-max-skill 원본대로 Gate 8 1순위 사용. 사용 전 README·디자인 프로세스 확인.
- [결정] grill-me로 원본 §5 4개 범주(업무범위/자동입력데이터/출력/배포환경)를 3~5개씩 질문. 이미 자료로 확인된 항목(xlsm 시트 구조, hwpx 이미지 개수, 배포방식 B안·완전오픈형 등)은 재질문하지 않음.
- [가정] 서식 개수는 22종(자동인식)이 아니라 **재추출 필요** — 문단·표 시퀀스 기반 구조 분석을 Gate 1에서 수행해 확정.
- [가정] 학생 개인식별정보는 수집하지 않는다(원본 §22 유지, 별도 확인 전까지 최소수집 원칙 적용).
- [가정] `UserForm_popup_교복_사전절차`는 코드만 남아있고 실체(.frm)가 없으므로, 교복 전용 입력 팝업은 기존 코드를 참고자료로만 쓰고 **신규 설계**한다.
