# P2-01 원본 보존형 F-007 명시 토큰 검증

- 상태: `자동 검증 PASS · Form ID 단위 분리 및 한컴/PDF 검토 전`
- 원본: `artifacts/hwpx/P0-02_원본사본.hwpx` (읽기 전용 사본)
- 템플릿: `artifacts/hwpx/P2-01/교복매뉴얼_F007_원본보존형_템플릿.hwpx`
- 골든 결과: `artifacts/hwpx/P2-01/교복매뉴얼_F007_원본보존형_골든결과.hwpx`

## 운영 원칙

원본은 하나의 복합 매뉴얼이고 `Contents/section0.xml` 하나에 모든 Form ID가 들어 있다. F-007만 임의로 잘라 새 HWPX를 재조립하면 표·이미지·페이지 구조가 달라질 수 있으므로, 이번 검증은 원본 전체를 사본으로 보존했다. F-007 시작 표제(`[ 6 ]`)와 다음 표제(`[ 7 ]`) 사이에서만 다음 예시값을 토큰으로 바꿨다.

| 원문 예시값 | 토큰 | 개수 |
|---|---|---:|
| `○ ○ 학 교` | `{{학교명}}` | 1 |
| `20○○학년도` 또는 `○○학년도` | `{{학년도}}` | 3 |
| `○○학교-○○(20○○.○.○.)`, `○○○○학교-` | `{{문서번호}}`, `{{발행일}}` | 2, 1 |

표·이미지·글꼴·스타일·F-007 경계 밖 XML은 바꾸지 않는다. 위원 성명, 업체 대표자명, 연락처, 서명, 직인 등은 토큰화하지 않는다.

## 실행 및 결과

```powershell
powershell -ExecutionPolicy Bypass -File scripts/prepare_f007_source_preserving_template.ps1
powershell -ExecutionPolicy Bypass -File scripts/verify_f007_source_preserving_template.ps1
```

2026-09-20 재실행 결과는 PASS였다. 검증기는 원본 SHA-256 불변, 원본·템플릿·골든 결과의 ZIP 엔트리 목록 일치, `Contents/section0.xml` 이외 모든 엔트리(이미지·스타일·메타데이터 포함)의 바이트 SHA-256 일치, 허용된 다섯 예시값→토큰 치환으로 계산한 template XML과 실제 XML의 완전 일치, 토큰→비식별 골든값 치환으로 계산한 output XML과 실제 XML의 완전 일치, XML 유효성 및 `kordoc@4.13.1 validate`(57개 엔트리)를 확인했다.

### 줄 배치 캐시·쪽수 위험 가드 보강(2026-09-20)

참고한 HWPX 실습 스킬의 레퍼런스 보존 원칙에 따라, 텍스트가 달라진 문단에 남은 `hp:linesegarray`는 한컴이 이전 줄 배치를 유지해 겹침·잘림을 낼 수 있는 캐시로 판단했다. 따라서 다음 보강을 적용했다.

1. `prepare_f007_source_preserving_template.ps1`는 F-007 예시값을 토큰화한 문단에서만 `linesegarray`를 제거한다.
2. `hwpx_token_fill.ps1`는 토큰을 값으로 치환한 문단에서만 같은 캐시를 제거한다. 문단·표·스타일 참조와 F-007 경계 밖 XML은 그대로 보존한다.
3. `verify_f007_source_preserving_template.ps1`는 캐시 제거를 허용 변경으로 정확히 재현하고, 원본 대비 F-007 문단 수 및 각 문단의 비공백 텍스트 길이 변화를 검사한다. 골든값 기준 최대 변화는 42.86%이며, F-007 공통 토큰의 제한된 치환 특성에 맞춰 50%를 초과하면 실패 처리한다.

재생성한 골든 결과에서 값이 반영된 6개 문단 모두 `linesegarray`가 제거됐음을 확인했다. 참고 스킬의 `page_guard.py`도 원본·골든 결과 비교에서 문단/표/pageBreak 구조와 전체 텍스트 길이 편차를 통과했다(문단별 허용 변화 50% 적용). 이 검사는 조판 위험을 줄이는 정적 가드이며, 실제 한컴 열기·PDF 육안 비교를 대체하지 않는다.

### 한컴 열기 상태(2026-09-20)

Windows HWPX 연결은 `Hwp.Document.hwpx.96`, 실행 파일은 `C:\Program Files (x86)\Hnc\Office NEO\HOffice96\Bin\Hwp.exe`로 확인됐다. 골든 결과를 이 한컴 NEO 인스턴스에서 열었고 응답 상태와 문서 창 제목을 확인했다. 다만 이 세션의 네이티브 화면 캡처 연결은 한컴 창을 읽지 못해 표·줄바꿈·이미지·페이지를 육안 판정할 수 없었다. 따라서 이는 **열기 가능성 확인일 뿐 P2-02 한컴/PDF 사람 검토의 완료 증빙이 아니다**. 열린 창에서 담당자가 F-007 경계의 제목·두문·본문·결문 및 PDF 페이지 수를 체크리스트와 대조해야 한다.

## 남은 작업

이 산출물은 전체 매뉴얼 사본이므로 단일 F-007 출력본이 아니다. 운영 배포 전에는 한컴에서 Form ID 단위 선택 출력 또는 스타일·표·이미지를 보존하는 안전 분리 방법을 확정해야 한다. 그 결과로 생성한 Form ID 단위 템플릿과 골든 결과만 P2-02 한컴/PDF 비교 대상으로 삼는다. 기존 라벨 기반 재구성 HWPX 및 SVG는 기술 탐색 참고물이며 운영 검토 대상이 아니다.
