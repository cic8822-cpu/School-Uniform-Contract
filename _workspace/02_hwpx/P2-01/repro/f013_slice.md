# OOOO학교 교복 디자인 및 규격서 (표준 예시)

※ 본 규격서 표준 예시는 업체에서 교복 제작에 어려움이 없도록 각급 학교에서 규격서 작성 시 따라야 할 통일된 표준안이며, 학교 상황에 맞게 항목과 내용(섬유 혼용률 등)을 수정하여 사용.

**1. 섬유혼용률**

| 구분 |  | 섬유 혼용률 | 비고 |
| --- | --- | --- | --- |
| 동복 | 재킷 | 모 80%, 나일론 20% | 캐시미어 |
|  | 셔츠/블라우스 | 폴리에스터 75%, 레이온 25% | 모슬린 |
|  | 바지 | 폴리에스터 65%, 레이온 30%<br>우레탄 5% | 링클프리 T/R 스판 |
| 하복 | 셔츠/블라우스 | 폴리에스터 75%, 레이온 25% | 모슬린 |
|  | 생활티 | 폴리에스터 100% | 쿨맥스/쿨론 |
