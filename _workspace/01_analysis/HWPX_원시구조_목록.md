## 4. P1-02 인계 사항

1. 원시 표제 후보는 58개이며, 사용자 목표 57종과 1건 차이가 있음. `[9-7]` 표제가 두 번 사용된 점, 안내 기안문과 붙임 서식의 포함 관계, 참고자료의 MVP 포함 여부를 분리해 Form ID를 부여해야 함.
2. 127개 표와 46개 추출 이미지는 독립 서식 수가 아니므로, 각 표·이미지의 소속 표제와 반복행·병합·이미지 배치 여부를 P1-02에서 기록해야 함.
3. 페이지에 걸친 표의 정확한 경계는 Kordoc 렌더 경고가 있어 한컴/PDF 검증 전 확정하지 않음.
4. 학생·학부모 개인정보, 직인·서명 자동처리는 MVP 범위에서 제외함.
