## 결론

기초자료의 공통값·위원 역할·업체명 반영, 선택 출력 차단, A4 인쇄 설정은 새 3종에서 확인됐다. F-041~F-043은 이전의 금액 공란 출력 위험이 보강되어, 최신 `verify_v1_log.txt`에서 금액·수량·납품/제출기한 누락 시 거부하는 회귀 검사를 통과했다.

그러나 F-038은 기초자료 업체 10행 중 앞의 4행만 인쇄하면서 출력 가능 검증은 10행 전체를 허용한다. 또 새 3종의 PDF 육안 확인 증빙이 없고, HWPX는 F-007 사본 단일 토큰 실험만 완료되어 Excel 사용자 흐름·한컴/PDF 비교가 연결되지 않았다. 활성 Phase의 X-06도 FAIL이며 품질 게이트가 종료 코드 2로 차단했다.

## 결함

### High — F-038에서 5~10번째 업체가 출력에서 조용히 누락됨

- Form ID: F-038
- 재현: 기초자료입력 `B44:B49`에 완전한 업체 6개를 입력하고 F-038을 선택 출력한다.
- 기대: 원본의 4행 서식 한계를 명시적으로 강제해 5개 이상이면 출력을 차단하거나, 추가 업체를 별도 페이지/서식으로 모두 출력해야 한다.
- 실제: 구현은 F-038의 `B9:B12`에 `B44:B47` 네 행만 참조한다(`build_excel_v1_structure.ps1` F-038 블록). 반면 `검증_F038출력가능`은 `B44:B53` 전체를 검사하고 1개 이상이면 허용한다. 5~10번째 업체는 PDF에 나타나지 않는다.
- 차단 여부: 차단. 평가 참여 업체가 누락된 등록부가 출력될 수 있다.
- 조치: `검증_F038출력가능`을 최대 4개로 제한하고 5개 이상 명확한 오류를 표시하거나, 원본 조판을 보존한 복수 페이지 출력을 설계하고 해당 경로의 회귀/PDF 검증을 추가한다.

### High — HWPX 출력은 실제 업무 흐름 및 한컴/PDF 검증이 완료되지 않음

- Form ID: F-007 (전체 HWPX 출력 경로)
- 기대: 기초자료 입력 → 선택 Form ID → 허용 공통값만 사본 HWPX에 반영 → validate·재열기·한컴/PDF 비교가 한 흐름으로 확인되어야 한다.
- 실제: `hwpx_token_fill.ps1`은 Excel VBA에서 호출하지 않는 독립 CLI이며, 검증은 인위적으로 토큰화한 F-007 사본 하나와 Kordoc SVG 렌더까지다. P2-02 한컴 수동 열기·PDF 비교는 TODO다.
- 개인정보 판단: `{{교장명}}`은 개인식별정보 경계상 허용하지 않는다. 이번 허용 목록의 `학교명, 학년도, 문서번호, 발행일, 제목, 수신기관, 시행일, 공개구분`만 자동 치환 가능하며, 교장명·성명·서명·직인·연락처는 빈 양식/수기 경계를 유지해야 한다.
- 차단 여부: 차단. HWPX 자동출력 완료 또는 P3 완료로 표시할 수 없다.

### Medium — 새 3종의 PDF/조판 검증이 파일 생성 및 페이지 나눔 확인에 머묾

- Form ID: F-037, F-038, F-040
- 실제: Excel 읽기 전용 검사에서 A4·100%·H/V 페이지 나눔 0은 확인했지만, 이 3종의 PDF 파일·A4 MediaBox·페이지 수·표/문장/서명란 잘림에 대한 독립 증빙을 찾지 못했다. 기존 F-041~F-043 PDF 증빙을 새 3종에 전용할 수 없다.
- 조치: 비식별 사본으로 서식별 단일 PDF를 출력하고 A4 1쪽 및 원문 표 구조/줄바꿈/공란을 렌더·육안 확인해 기록한다.

### Medium — PDF/미리보기 예외 시 임시 시트 정리 보장이 소스 수준에서 없음

- Form ID: F-015~F-025 선택 출력 경로
- 실제: `선택서식_PDF저장_실행`과 미리보기는 성공 호출 뒤에만 `F015임시시트정리`를 실행한다. PDF 엔진·프린터·파일 잠금 오류를 유도한 `Finally` 경로는 없다. 최신 정상 실행 로그의 임시 시트 0건은 실패 경로의 보증이 아니다.
- 조치: 생성 직후 이름을 추적하고 `On Error GoTo Cleanup` 단일 정리 경로에서 삭제·`DisplayAlerts` 복원을 보장하며, 강제 Export 실패 회귀 검사를 추가한다.

### Medium — 새 HWPX 스크립트의 린트·실패 임시파일 정리가 훅에 포함되지 않음

- 실제: 훅의 PSScriptAnalyzer 목록은 Excel 빌더/검증기 및 훅 자신만 포함한다. `scripts/hwpx_token_fill.ps1`, `scripts/verify_hwpx_token_fill.ps1`은 제외된다. 검증 폴더에는 실패/중단 실행에서 남은 숨김 `.tmp` 파일 4개가 관찰되었다. 최종 `OutputPath`는 원자적 교체로 보호하지만 실패 임시파일 제거는 보장되지 않는다.
- 조치: 두 스크립트를 파서·PSScriptAnalyzer 대상에 추가하고 `finally`에서 생성한 임시파일을 삭제한다. 실패 중간 단계 회귀 검사를 추가한다.
