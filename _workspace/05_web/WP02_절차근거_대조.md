# WP-02 계약절차 근거 대조

- **작성일**: 2026-09-25
- **목적**: Workflow Master의 단계·주의사항·계약방법 적용 상태를 원문 또는 Excel 안내 원문과 구분하여 기록한다.
- **원칙**: 매뉴얼에 없는 절차·법정기한·금액기준을 새로 만들지 않는다. 근거가 부족하면 웹 화면에서 “매뉴얼 확인 필요”로 표시하고 확정 Stepper 진행을 허용하지 않는다.

## 1. 공통 근거

| 대상 | 직접 근거 | 데이터 반영 |
|---|---|---|
| 2단계입찰 추진 절차 | `교복 매뉴얼 작성서식0908(안정구 추가)-1.hwpx`의 **3 추진 절차 개요** 및 **교복 납품 사업자 선정** | `WF-BID`의 CM-03 범위를 확정으로 표시. 품질 심사 후 가격 심사라는 순서를 안내함. |
| 4·5·11단계 화면 안내 | `scripts/build_excel_v1_vba.ps1`의 `frmContractGuide.초기화` 배열(`stepNames`, `stepDescriptions`, `stepFormIDs`) | Workflow 단계명·설명·관련 Form ID를 원문 그대로 이식. 각 Step의 체크리스트는 해당 설명의 보존 추출임. |
| 업무·법령 최종 확인 | 매뉴얼 원문과 Excel 안내 모두 계약방법별 적용 요건을 자동 판정하지 않음 | 모든 Step에 현행 법령·금액기준·기한 최종확인 주의사항을 표시함. |

## 3. 단계 데이터 규칙

1. `checklistItems`는 Excel 단계 설명을 임의 요약하지 않고 보존 추출한다.
2. `cautions`는 해당 단계가 자동 계약판정·법률 자문이 아님을 알리고, 근거 상태가 `manual-confirmation-required`이면 반드시 확인 필요 배지를 표시한다.
3. `manualReferences`는 CM-03에서 매뉴얼 장절을, CM-01·CM-02에서는 근거 미확정 상태를 함께 기록한다.
4. UI는 `evidenceStatus`와 `workflowBinding.actionable`을 읽어 확정 절차·참고 절차를 구별한다.
5. 이는 `0-1.교복계약 웹앱개발-프롬프트.txt`의 “관련 규정/주의사항” 및 `0-2.교복 학교주관구매 웹앱 — 화면 구성 및 디자인 계획.md` §4의 근거 상태와 일치한다. 수의계약의 개별 매뉴얼 장절이 제공되지 않은 경우에는 Excel 원문 위치를 표시하고 “매뉴얼 확인 필요”를 함께 노출한다.
