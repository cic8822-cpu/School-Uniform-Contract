## 2. High

### H-1. 서명란 서식(F-002·F-003·F-037·F-040)의 입력 필드에 R-02(위원 성명, 2026-09-23부터 실명)가 들어 있고, "출력 금지"를 표시하는 값이 없음

- **파일·위치**
  - `forms.json` → F-002·F-003·F-037·F-040 `inputFieldIds`에 `R-01`, `R-02` 포함
  - `fields.json` → `fields[fieldId=R-02].usedByForms` = `F-001, F-002, F-003, F-034, F-037, F-040`
- **근거**
  - `서식_매핑표.md` §6(2026-09-23): "F-002·F-003·F-027·F-030·F-037·F-040처럼 위원·서약자 본인이 자필로 성명·서명을 직접 쓰는 서식은 이번 정책 확대와 무관하게 **계속 빈칸으로 유지함**(… 서명 자리와 표기 자리를 구분한다는 사용자 지시)."
  - 같은 서식의 매핑표 §2 경계 문구: F-002/F-003 "성명·서명란은 빈칸 유지", F-037 "참석자 성명·서명은 빈칸 유지", F-040 "위원 성명·서명은 빈칸 유지".
  - 실제 Excel: `build_excel_v1_structure.ps1`에서 위원 반복행(C58:C67)을 참조하는 서식 시트는 F-001·F-006·F-025·F-034뿐이고, F-002·F-003·F-037·F-040은 참조하지 않음. `verify_excel_v1.ps1` 348·358·443행은 `홍길동`(마스킹 시험 실명)이 F-002·F-003·F-040 본문에 **나오지 않아야** 통과하는 회귀 검사임.
- **위험**: 웹 구현자가 `inputFieldIds`/`usedByForms`로 자동반영 대상을 정하면, 위원 실명이 자필 서명 자리에 인쇄됨. 사용자가 명시적으로 금지한 동작이고, Excel 회귀 검사와도 반대 결과가 나옴. 경계 문구가 `boundary` 문자열에만 있어 기계적으로 적용할 수 없음.
- **확인 방법**: `forms.json`에서 `formId in (F-002,F-003,F-037,F-040)`의 `inputFieldIds`에 `R-02`가 있고, 이를 막는 구조화 필드(예: 서식별 출력 제외 목록)가 없는지 확인.
- **수정 요구(택1, 데이터만 수정)**: (a) 네 서식의 `inputFieldIds`와 R-02 `usedByForms`에서 R-02를 빼고, 필요하면 R-01도 뺌(Excel이 위원 반복행을 참조하지 않으므로). 또는 (b) 서식별 `blankFieldIds`(인쇄 시 반드시 빈칸) 같은 구조화 필드를 추가해 R-02를 넣음. 같은 원칙이 적용되는 F-027·F-030도 함께 점검함(현재 두 서식에는 R-02가 없어 해당 없음, R-03 업체명은 서명과 별개라 허용).
