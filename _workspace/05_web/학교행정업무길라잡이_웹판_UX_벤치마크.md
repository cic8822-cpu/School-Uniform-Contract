# 학교행정업무 길라잡이 웹판 UX 벤치마크

- **분석일**: 2026-09-16
- **대상**: [학교행정업무 길라잡이 웹판](https://jbe-guide.vercel.app/)
- **분석 범위**: 공개 홈, `학교회계 계약 → 계약 방법 → 입찰` 화면의 실제 브라우저 탐색
- **분석 원칙**: 화면·코드·문구를 복제하지 않고, 교복계약 자동화에 적용 가능한 정보 구조와 상호작용 원칙만 추출함.
- **관찰 한계**: 페이지 자원 하나에서 HTTP 503 콘솔 오류가 있었으나 홈·분야 선택·상세 업무 탐색은 가능했음. 서버 내부 구현과 검색 색인 기준은 확인하지 못함.

## 1. 확인한 화면·흐름

| 구간 | 실제 관찰 | 재사용 판단 |
|---|---|---|
| 홈 탐색 | 상단 통합 검색, 추천 검색어, 분야별 아코디언 목록을 제공함 | 적용: 교복 절차·서식·질문을 하나의 검색 진입점으로 제공 |
| 분야 진입 | 분야를 먼저 고르면 업무 목록과 각 업무의 세부 단계 수를 보여 줌 | 적용: 교복구매 단계를 우선 제시하고 단계별 관련 Form ID 개수를 표시 |
| 업무 상세 | `다른 업무 선택`, 업무 번호·제목, 접히는 목차와 현재 단계 표시를 제공함 | 적용: 선택한 사업의 단계 위치와 이전/다음 단계를 항상 표시 |
| 단계 본문 | 표와 목록으로 처리 항목, 기한·경로·주의사항을 함께 제시함 | 적용: 단계별 해야 할 일, 입력 필요값, 주의사항, 출력 가능 서식을 한 화면에 배치 |
| 근거 연결 | 단계 하단에 관련 서식·법령 근거를 분리해 제공하고 원문 PDF 링크를 둠 | 적용: Form ID별 미리보기/생성 버튼과 원본 매뉴얼 위치·근거를 함께 제시 |
| 신뢰 고지 | 웹판은 탐색용이며 최종 판단은 최신 공식 원문을 확인하도록 안내함 | 필수 적용: 자동 생성 결과도 행정실 담당자가 사실관계·계약조건·서식 상태를 확인해야 출력 가능 |
| 접근성 기본 | 본문 바로가기, 의미 있는 제목 구조, 버튼·링크 레이블, 이전/다음 이동을 제공함 | 필수 적용: 키보드 탐색, 명확한 버튼명, 현재 단계 텍스트 표시, 색상 외 상태표시 |

## 2. 교복계약 웹앱에 채택할 구조

```mermaid
flowchart LR
  A[통합 검색·추천 업무] --> B[교복구매 9단계]
  B --> C[단계 상세]
  C --> D[해야 할 일·주의사항·근거]
  C --> E[관련 Form ID]
  E --> F[기초자료 입력·누락 검사]
  F --> G[미리보기·PDF 또는 검증된 HWPX 생성]
  G --> H[행정실 최종 확인]
```

1. **탐색과 작성 분리**: 처음에는 개인정보 없이 절차·서식·근거를 찾고, `서식 작성`을 선택한 뒤에만 필요한 입력 화면으로 이동함.
2. **단계 중심 내비게이션**: 9단계 진행 순서, 현재 단계, 이전·다음 이동, 단계별 Form ID와 완료 상태를 제공함.
3. **점진적 입력**: 해당 단계와 선택한 서식에 필요한 필드만 표시하며, 필수값 누락은 입력칸 가까이에 텍스트로 안내함.
4. **근거와 생성물 동시 제공**: 생성 버튼 옆에 원문 매뉴얼 위치, 적용 주의사항, 생성 형식(PDF/HWPX)과 HWPX POC 검증 상태를 표시함.
5. **안전한 출력 확인**: 생성 전 요약 확인 화면을 두고, 개인정보·서명·직인은 자동 처리하지 않으며 행정실 담당자의 최종 확인을 요구함.

## 3. 적용하지 않는 요소

- 참고 웹판의 문구·콘텐츠·시각 자산·코드를 복제하지 않음.
- 검색 결과가 곧 법령·계약 판단을 확정하는 것처럼 처리하지 않음.
- 확인되지 않은 교복계약 기한·금액 기준을 웹앱 규칙으로 하드코딩하지 않음.
- 학생·학부모 개인식별·연락처·치수·설문 원자료와 직인·서명을 웹 입력·저장·자동 생성 범위에 포함하지 않음.

## 4. 웹 MVP 수용 기준 제안

| ID | 수용 기준 |
|---|---|
| W-01 | 사용자가 검색 또는 9단계 목록에서 업무 단계와 관련 Form ID로 이동할 수 있음 |
| W-02 | 상세 화면에 해야 할 일·주의사항·공식 근거·관련 서식이 분리되어 표시됨 |
| W-03 | 작성 화면은 선택한 서식에 허용된 필드만 표시하고, 필수값 오류를 해당 입력칸 가까이에 텍스트로 표시함 |
| W-04 | 이전/다음 단계, 본문 바로가기, 키보드 조작, 명시적 버튼 레이블, 색상 외 상태표시를 제공함 |
| W-05 | 생성 전 확인 화면과 행정실 최종 확인 안내를 제공하며, HWPX는 P2-03 승인 범위에서만 활성화함 |
| W-06 | 웹앱은 최신 공식 원문 확인 안내와 원본 자료 링크를 제공함 |
