# F-045 교복구매 사전 안내 가정통신문 구현 명세

- 원문 위치: HWPX 74쪽 `[17-1]`
- 상태: `구현 전 · 원문/매핑 대조 완료`
- 목적: 신입생 교복 구매 사전 안내문을 A4 자연 배율로 출력한다.

## 원문 보존 요소

1. 표제: `초 6(예비 중1), 중 3(예비 고1) 교복 구매 사전 안내`
2. 인사말, 신입생 배정 전 안내, 학교주관구매 제도·상한가·유의사항 안내, 감사 인사
3. 발행일과 `○○학교장` 자리

## 자동 반영과 금지 경계

| 구분 | 값 | 반영 위치 |
|---|---|---|
| 허용 | C-01 학교명 | 본문 학교명·`학교장` 표기 |
| 허용 | C-02 학년도 | 신입생 배정·교복 안내 문장 |
| 허용 | B-01 구매명 | 구매 안내 문장 |
| 허용 | D-02 문서 제목 | 표제 또는 보조 표제 |
| 금지 | 학생·학부모 성명·연락처·배정번호·개별 신청/치수/수량 | 입력·저장·출력하지 않음 |

## 완료 검증

- 원문 제목·7개 안내 문단·발행일·학교장 표기 대조
- 골든 입력의 학교명·학년도·구매명·제목이 실제 시트 수식 결과에 반영됨
- 개인정보 형태 문자열이 본문에 없음
- 선택 출력은 공통 필수값을 요구함
- A4 1쪽 자연 배율, PDF 렌더링 잘림 없음
