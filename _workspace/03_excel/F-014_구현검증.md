# F-014 제안서 평가항목 및 배점기준 구현·검증

- **상태**: `구현·검증 완료 — 안전 빌드(v13) 통과, verify_v1_log.txt 전 항목 PASS. 단, 원본 예시안의 평가구분·배점기준·가감점 확정과 한컴 수동 대조는 범위 밖(4장 한계 참고). P3-01 전체는 여전히 IN_PROGRESS.`
- **Form ID**: `F-014`
- **원본 대조 대상**: `교복4차 (2)/교복 매뉴얼 작성서식0908(안정구 추가).hwpx`의 `[9-3] [붙임 3] 제안서 평가항목 및 배점기준`
- **원본 보호**: HWPX는 `ZipArchive.OpenRead()`로만 읽었으며 수정하지 않음. 생성본은 `artifacts/excel/`에 새 버전으로만 저장함.

## 3. 검증 범위

안전 빌드에서 다음을 Excel COM 사본으로 확인한다.

1. 정상값 및 복수 평가행이 F-014 표와 총점에 반영되는지
2. 필수값 누락, 평가 고아행, 배점 초과가 F-014 선택 출력에서 차단되는지
3. 최대 길이·특수문자 공통값이 F-014 수식에 오류 없이 표시되는지
4. F-007/F-024, DB 저장·수정·불러오기 회귀와 F-014 포함 PDF를 확인하는지
5. 외부 링크, 연결, `#REF!` 이름 정의가 각각 0건인지

## 4. 한계

- 원본은 학교 상황에 맞는 정량·정성 평가기준, 가점·감점과 상세 설명을 예시로 제시함. 현재 입력 모델 R-07에는 평가구분·배점기준·가감점 전용 필드가 없으므로 이 값들을 자동 확정하거나 판정하지 않음.
- 실제 평가위원의 성명·연락처·서명과 업체 식별정보는 F-014에 입력·저장·출력하지 않음.
- 원본 HWPX와 픽셀 단위 동일 조판 또는 한컴 수동 열기는 이 Excel 구현의 검증 범위가 아님.
