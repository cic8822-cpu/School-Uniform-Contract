# F-018 정량적 평가 자기 평점표 구현·검증

## 요약

- 원문 HWPX `[9-7] [서식 1_1] 정량적 평가 자기 평점표`의 4개 정량 항목과 50점 배점표를 Excel로 재구성함.
- 학교 F-015 평가와 업체 F-018 자기평점을 별도 입력 열과 별도 DB로 분리함.
- 작성자·대표자·서명은 개인정보 경계에 따라 빈 양식으로 유지함.

## 구현 범위

| 구분 | 구현 내용 | 경계 |
|---|---|---|
| 입력 | `기초자료입력!N44:Q53`의 수행경험·공인인증·거리·상한가격 자기평점 | F-015의 `C:F`와 혼용 금지 |
| 저장 | `DB_자기평점`에 레코드순번·업체행번호·4개 점수 저장 | `DB_정량평가`와 분리 |
| 출력 | 선택한 업체별 임시 시트 `F018_임시_*`를 PDF에 결합 | 유효 업체만 출력 후 임시 시트 삭제 |
| 개인정보 | 업체명만 R-03에서 반영 | 작성자·대표자·서명·연락처 자동 반영·저장 금지 |

## 검증 결과

- `scripts/run_build_excel_v1_structure_utf8.ps1` 안전 빌드 PASS.
- 배포 후보 `artifacts/excel/교복구매_길라잡이_20260917_v7.xlsm` 생성.
- `verify_excel_v1.ps1`에서 학교 F-015 10점과 업체 F-018 8점의 분리, 0점 포함 정상 입력, 배점 초과·고아 입력 차단, 저장·수정·불러오기, PDF 임시 시트 정리를 PASS로 확인.
- 빈 F-018 PDF를 렌더링해 A4 1쪽, 페이지 나눔 0건, 빈 자기평점·작성자·대표자·서명란을 직접 확인.
