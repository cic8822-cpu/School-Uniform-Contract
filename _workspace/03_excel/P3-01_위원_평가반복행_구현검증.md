- 구현일: 2026-09-16
- 대상 안전 빌드: `artifacts/excel/교복구매_길라잡이_20260916_v11.xlsm`
- 적용 Form ID: F-001~F-003, F-014~F-016, F-018, F-034~F-040의 향후 입력 기반이 되는 R-01, R-02, R-07. 이번 단위에서는 개별 출력 서식 시트를 추가하지 않음.

## 구현 범위

| 구분 | 적용 필드 | 구현 |
|---|---|---|
| 위원 반복행 | R-01 역할·직위, R-02 마스킹 식별표시 | `기초자료입력!B58:C67` 입력, `DB_위원`에 레코드순번·행번호·역할직위·마스킹식별표시로 정규화 저장, 저장·수정·불러오기 연계 |
| 평가점수 반복행 | R-07 평가점수, K-03 평가 총점 | `기초자료입력!B72:D81`에 평가항목·배점·점수를 입력하고 `D82`에서 점수 합계를 수식 계산, `DB_평가`에 정규화 저장, 저장·수정·불러오기 연계 |
| 개인정보 경계 | R-02 | 실제 성명·연락처·서명은 입력·저장하지 않음. 마스킹 식별표시는 `위원 ○○`, `위원 **`, `평가위원 ○○`, `평가위원 **` 계열의 제한 형식만 허용함. |
| 내부 DB 경계 | DB, DB_품목, DB_업체, DB_위원, DB_평가 | DB는 숨김·보호, 반복 DB는 VeryHidden·보호함. 비밀번호는 사용하지 않으며 `Workbook_Open`에서 `UserInterfaceOnly`를 재설정해 매크로 저장·수정·불러오기만 허용함. 이는 우발적 편집 방지일 뿐 보안 경계가 아니며, `Workbook_BeforeSave`가 전체 내부 DB를 재검증해 무효 데이터가 있으면 저장을 취소함. |

## 유효성 검사

- 위원 행은 역할·직위와 제한된 마스킹 식별표시가 함께 있어야 하며 각각 2~50자임.
- 위원 역할·직위 중복은 저장·수정 시 사용자에게 경고함.
- 평가 행은 평가항목(2~100자), 0 이상 배점, 0 이상·배점 이하 점수가 모두 있어야 함.
- 빈 반복행은 저장하지 않으며, 불완전 행·배점 초과 점수는 저장을 차단함.

## 한계와 다음 연결점

- 현재 F-001~F-003 및 F-014~F-040 개별 출력 서식은 아직 미구현이므로, 이 반복행은 입력·정규화 저장·검증 기반까지만 제공함.
- 실제 성명·연락처·서명은 이 XLSM의 입력·DB·검증 로그에 포함하지 않음. 행정실 담당자가 출력 전 역할 구성·평가 사실관계를 최종 확인해야 함.
- 비밀번호 없는 숨김·보호는 사용자가 해제할 수 있으므로 보안 경계가 아니다. 이 구현은 매크로가 허용된 Excel에서 저장 전 데이터 유효성을 강제하는 완화 통제이며, 파일 접근 자체를 암호화하거나 악의적 우회를 막지는 않는다.
