# F-010 사전규격공개 기안문 구현 명세

원본: HWPX 18쪽 `[8]`.

- 제목: `○○학년도 학생 교복 입찰 사전규격 공개`.
- 본문 항목: 사업명, 기초금액, 배정예산, 공개방법(G2B), 공개사항, 사전공개기간, 의견등록마감일시.
- 자동 반영: 학교·학년도·구매명(C-01/C-02/B-01), 기초금액(B-04), 예정수량(B-05), 제출기한(B-07), 문서 제목(D-02).
- 수기 유지: 결재·주소·전화·이메일 및 공개 세부 일정의 법정 적정성 확인.
- 산식: 배정예산은 기초금액×예정수량을 자동 확정하지 않으며, 원문 단가·수량 구성과 예산 승인은 담당자가 확인한다.
