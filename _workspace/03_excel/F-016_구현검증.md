# F-016 정성적 평가 구현·검증

- **상태**: `DONE — 입력·저장·수정·불러오기·저장경계·선택 출력·PDF 결합까지 구현하고 안전 빌드 전체 PASS`
- **Form ID**: `F-016`
- **원본 대조 대상**: `교복4차 (2)/교복 매뉴얼 작성서식0908(안정구 추가).hwpx`의 `[9-5] [붙임 3_2] [2단계] 정성적 평가`
- **검증 배포본**: `artifacts/excel/교복구매_길라잡이_20260917_v3.xlsm`

## 1. 입력·표현 범위

F-016은 **교복선정위원회**가 평가하는 정성평가입니다. 원문 4개 고정 항목인 재질 15점, 완성도 10점, A/S 15점, 하자보상 10점과 가점·감점 요인을 반영했습니다. 단계별 판단 결과를 자동 추정하지 않도록, 담당자가 확정한 최종 숫자만 입력하고 범위만 검증합니다.

- `기초자료입력!H44:L53`에 업체별 재질·완성도·A/S·하자보상·가감점을 입력하며 `M44:M53`에서 완전성을 표시합니다.
- 허용 범위는 각각 `0~15`, `0~10`, `0~15`, `0~10`, `-15~+5`이며, 업체명 없는 점수 또는 일부 항목만 입력한 행은 거부합니다.
- 개인식별정보, 연락처, 서명과 설문 원자료는 입력·저장·출력하지 않습니다.

## 2. 구현 내용

- `DB_정성평가`에 레코드순번·업체 행번호·5개 점수를 정규화하여 저장합니다. 시트는 VeryHidden·보호 상태이며 `Workbook_Open`에서 `UserInterfaceOnly`를 재적용합니다.
- `정성평가행검증`, `정성평가복사_기초자료_DB`, `저장경계검증`을 추가하고 저장·수정·불러오기 흐름에 연결했습니다.
- `F-016_정성적평가`는 `I3`의 선택 업체 순번과 `INDEX` 수식으로 해당 업체만 표시합니다. 합계는 `F9:F13`의 다섯 값이 모두 있을 때만 계산합니다.
- `검증_F016출력가능`, `F016업체행완전한가`, `F016임시시트생성`을 추가했습니다. 선택 출력은 완전한 업체별 평가표를 임시 시트로 생성해 다른 선택 서식과 하나의 PDF로 결합하고, 종료 후 임시 시트를 삭제합니다.
- `서식선택_출력`에서 F-016은 `Y`, 연결 시트는 `F-016_정성적평가`로 표시됩니다.

## 3. 검증 결과

`scripts/run_build_excel_v1_structure_utf8.ps1`를 실행해 `교복구매_길라잡이_20260917_v3.xlsm`을 생성했고, `verify_excel_v1.ps1` 전체 PASS를 확인했습니다.

- 정상 2개 업체의 저장, 업체별 점수 전환, 합계, 수정, 불러오기 복원을 검증했습니다.
- 배점 초과, 업체명 없는 고아 점수, 직접 DB 가감점 범위 초과를 차단했습니다.
- `Workbook_Open` 재열기 후 `DB_정성평가`의 `ProtectionMode`를 확인했습니다.
- F-016을 포함한 선택 PDF 생성, F016 임시 시트 정리, 외부 링크·연결·`#REF!` 0건을 검증했습니다.
- 최종 XLSM을 읽기 전용으로 다시 열어 제목·머리글·수식·인쇄영역·F-016 선택 상태·PDF 버튼 연결·DB 보호를 직접 확인했습니다.

## 4. 남은 범위

F-016 단위는 완료했으나 P3-01 전체는 완료가 아닙니다. F-013 HWPX 경로와 미구현 Form ID, 기준 XLSM 전체 기능 동등성인 X-06은 계속 차단 상태입니다.
